# Киноуроки: копия кабинета на Laravel

Это копия личного кабинета lk.kinouroki.org на том же стеке, что и боевой сайт: Laravel, Blade и Bootstrap 5.2. Разметка и классы повторяют прод. Стили и скрипты подключаются боевые, прямо с lk.kinouroki.org. Наши улучшения лежат рядом отдельными файлами, поэтому разработчик переносит их копированием, а не переписыванием.

**Посмотреть:** https://daridarom.github.io/kinouroki-lk/films/

## Что улучшено: адаптивность

| Где | Было на проде | Стало |
|---|---|---|
| Сетка фильмов | `.film-card { width: 24% }` на любом экране: на телефоне 3–4 карточки шириной около 100 px, названия обрезаны до «Ста…» | Сетка сама подбирает число колонок: 1 на телефоне, 2 на планшете, 3–4 на компьютере |
| Карточка фильма | Постер и название в одну строку с обрезкой | Постер 16:9, название в две строки, метка качества, ступени, год |
| Каталог | 3 страницы по 32 фильма, без поиска | Поиск, фильтры по качеству и ступени, сортировка, все фильмы на одной странице |
| Страница фильма, телефон | Сначала длинное описание с выравниванием по ширине и «дырами» между словами, видео далеко внизу | Сначала видео и кнопка «Провести киноурок», текст ровный и читаемый |
| Вкладки фильма | Переносятся в несколько строк | Прокручиваются вбок |
| Плееры | Rutube и mp4 грузятся сразу, даже в скрытых вкладках | Загружаются по нажатию |
| Фото | Одна колонка на телефоне, у всех фото alt «Название фильма» | Две колонки, у каждого фото своё описание |
| Социальные практики | Страница шире экрана из-за пагинации, фильтр занимает весь первый экран, пустые списки ничего не показывают | Фильтр свёрнут под кнопку, пагинация помещается в экран, у пустых списков есть подсказка |
| Киноурок | Имя файла методички выходит за экран | Имя переносится |
| Статистика | Подсказки не открываются (атрибуты Bootstrap 4), таблицы обрезаны | Подсказки открываются, таблицы прокручиваются вбок |

Ступени обучения в копии совпадают с настоящими категориями кабинета: `/films/category/1–3` («Начальная школа», «Основная школа», «Средняя школа»).

## Как перенести в боевой проект

Подробная пошаговая инструкция: **[ПЕРЕНОС.md](ПЕРЕНОС.md)**. Коротко:

1. Скопировать `public/css/kinouroki-adaptive.css` и `public/js/kinouroki-adaptive.js` и подключить их в layout после `app.css` и `app.js`.
2. Добавить компонент `resources/views/components/film-card.blade.php`.
3. В шаблоне списка фильмов заменить разметку карточки на `<x-film-card :film="$film" />` и добавить форму фильтров.
4. В шаблоне страницы фильма добавить классы `ka-film-body`, `ka-tabs`, `ka-player` и порядок блоков `order-*`.
5. В контроллере фильмов добавить scope `filter()`. Модель и существующие данные менять не нужно.

Все отличия от прода в Blade-файлах помечены комментарием `KINOUROKI-ADAPTIVE`.

## Запуск копии у себя

```bash
cd laravel
composer install
cp .env.example .env && php artisan key:generate
touch database/database.sqlite && php artisan migrate --seed
php artisan serve        # http://127.0.0.1:8000/films
```

Обновить ссылку для просмотра:
```bash
python3 scripts/export-static.py   # пересобирает ../docs
```
Затем сделать commit и push; GitHub Pages обновится сам.

```

  database/data/*.json   данные, снятые с публичных страниц 24.09.2026

```

## Ограничения копии

- Профиль, социальные практики, инициативы, черновики, киноуроки и статистика перенесены с настоящей разметкой, но **данные в них — примеры**: настоящих имён, школ и фото детей в копии нет. Таблицы статистики на проде строит Vue-компонент по API; в копии вместо них таблица-пример.
- Вход, регистрация и сохранение форм не работают.
- Пользователь в шапке ненастоящий, демонстрационный. Личных данных в копии нет.
- Описания фильмов и новости сокращены.
- Схема таблиц восстановлена по страницам сайта. При переносе нужно сверить её с настоящими миграциями.
