# Киноуроки: макет публичной части ЛК

Рабочий кликабельный макет публичной части lk.kinouroki.org. На нём мы проверяем улучшения, прежде чем передавать их разработчику боевого сайта. Живой сайт от макета не зависит, и макет в него ничего не пишет.

- **Данные:** сняты с публичных страниц сайта 24.09.2026. Это 67 фильмов, 16 последних новостей, документы, FAQ, вебинары, видеопрограммы и журналы.
- **Картинки и видео** не копировались: они подгружаются напрямую с lk.kinouroki.org, Rutube и YouTube.
- **Не входит в макет:** личный кабинет, вход и регистрация, раздел «Киноуроки» (требует входа) и «Социальные практики». Ссылки на них ведут на боевой сайт.
- **Тексты** описаний и новостей в макете сокращены. У каждой страницы есть ссылка на оригинал.

## Что уже улучшено

**Список фильмов** (`films/index.html`)
- Поиск по названию, качеству и описанию.
- Фильтр по качеству (67 качеств) и по ступени: начальная, основная, старшая школа.
- Сортировка: сначала новые, сначала старые, по алфавиту.
- Все фильмы на одной странице вместо трёх.
- Состояние фильтров сохраняется в адресе, поэтому подборку можно переслать ссылкой, например `?stage=primary&q=дружба`.
- В карточке: постер 16:9 без искажений, метка качества, анонс в 3 строки, ступень и год.
- Клик по метке качества на карточке сразу фильтрует список по этому качеству.

**Страница фильма** (`films/<id>.html`)
- Первый экран: плеер, название, качество, ступень и две главные кнопки: «Провести киноурок» и «Скачать фильм и методичку».
- Плеер загружается только по клику, поэтому страница открывается быстро и не грузит Rutube заранее.
- Вкладки вместо длинной простыни: «К уроку» (понятие, антипод, определение, цитата), «О фильме», «Материалы», «Фото», «Съёмки».
- Внизу блок «Ещё для этой ступени» и переход к соседним фильмам.

**Общее**
- Меню: 5 главных пунктов и «Ещё» вместо 13 пунктов подряд. На телефоне меню открывается кнопкой.
- Мобильная вёрстка без горизонтальной прокрутки.
- Фирменный синий `#4582ec` затемнён до `#2f6fdb`, чтобы белый текст на кнопках проходил проверку контраста AA (4.75:1 вместо 3.71:1).
- Нет внешних шрифтов, библиотек и счётчиков. Весь макет — это HTML, один CSS и три маленьких JS-файла.

## Как устроено

```
data/        данные, снятые с сайта (films.json, news.json, pages.json)
src/         шаблоны страниц (Jinja2): base, films, film, index, news, page
assets/      site.css, site.js, films.js, film.js, favicon.svg
build.py     сборка: data + src → docs/
docs/        готовый сайт (его отдаёт GitHub Pages)
AUDIT.md     найденные проблемы боевого сайта для разработчика
```

Пересобрать после правки: `python3 build.py` (нужен Python 3 и `pip install jinja2`).
Посмотреть локально: `cd docs && python3 -m http.server 8000`, затем открыть http://localhost:8000.

## Как переносить в боевой сайт

Боевой сайт написан на Laravel с Bootstrap 5, шаблоны Blade. Макет не копирует их код, а показывает целевое поведение.

1. **Карточка фильма.** Блок размечен комментарием `COMPONENT: film-card` в `src/_macros.html`. Нужные поля уже есть в модели фильма. Не хватает только отдельного поля «ступень», об этом написано в AUDIT.md, пункт 3.
2. **Фильтры.** Проще всего сделать их на клиенте, как в `assets/films.js`: 67 карточек помещаются на одну страницу. Если фильмов станет больше 200, лучше перейти на серверные фильтры по GET-параметрам с теми же именами: `q`, `quality`, `stage`, `sort`.
3. **Страница фильма.** Плеер сейчас в табах Bootstrap. Замена — ленивый iframe из `assets/film.js`.
4. **Стили.** Переменные в начале `assets/site.css` соответствуют переменным Bootstrap `--bs-*`.
