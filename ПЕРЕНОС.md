# Перенос улучшений в боевой lk.kinouroki.org

Инструкция для разработчика. Все шаги обратимы. Порядок выбран так, чтобы после каждого шага сайт оставался рабочим.

## Шаг 1. Стили и скрипт (15 минут, риск минимальный)

1. Скопировать в боевой проект:
   - `laravel/public/css/kinouroki-adaptive.css` → `public/css/kinouroki-adaptive.css`
   - `laravel/public/js/kinouroki-adaptive.js` → `public/js/kinouroki-adaptive.js`
2. Удалить из CSS блок **«0. Плашка копии»**: он нужен только копии.
3. В главном layout (там, где подключается `/css/app.css`) добавить:
   ```blade
   <link href="{{ asset('css/kinouroki-adaptive.css') }}" rel="stylesheet">   {{-- после app.css --}}
   ...
   <script src="{{ asset('js/kinouroki-adaptive.js') }}"></script>          {{-- после app.js --}}
   ```
   Если стили собираются через Laravel Mix, можно вместо этого сделать `@import` файла в `resources/sass/app.scss`.

Уже после этого шага на телефоне список фильмов перестраивается в 1–2 колонки, а текст описаний становится ровным.

## Шаг 2. Карточка фильма

1. Скопировать `laravel/resources/views/components/film-card.blade.php` → `resources/views/components/film-card.blade.php`.
2. Карточка использует:
   - `$film->posterUrl()` — на проде заменить на то, чем сейчас выводится постер, например `asset('storage/'.$film->poster)`;
   - `$film->categories` — связь с категориями `/films/category/{id}`, на проде она уже есть;
   - `$film->published_at`, `$film->quality`, `$film->lead()`.
   Метод `lead()` берёт из описания первый абзац без HTML. Его можно скопировать из `laravel/app/Models/Film.php`.
3. В шаблоне списка фильмов (`films/index`, а также страниц категорий) заменить цикл карточек на:
   ```blade
   <div class="row films row-cols-1 g-0 align-items-start" data-ka-grid>
       @foreach($films as $film) <x-film-card :film="$film" /> @endforeach
   </div>
   ```
4. В контроллере добавить `->with('categories')`, чтобы избежать N+1 запросов.

## Шаг 3. Поиск и фильтры

1. Скопировать `scopeFilter()` из `laravel/app/Models/Film.php` в модель `Film`. Имена колонок нужно сверить с настоящими.
2. В `FilmController@index` и в методе категорий:
   ```php
   $films = Film::with('categories')->filter($request->only('q','quality','sort') + ['category' => $categoryId])->get();
   ```
   Прод сейчас делит список на страницы через `paginate(32)`. Если фильмов станет больше 150, лучше вернуть `paginate(48)->withQueryString()`.
3. Скопировать форму фильтров: блок `<form … data-ka-filters>` из `laravel/resources/views/films/index.blade.php`.

## Шаг 4. Страница фильма

Изменения в `films/show`, в копии это `laravel/resources/views/films/show.blade.php`:
- у карточки описания (`div.card.p-3.pt-4`) добавить классы `ka-film-body order-2 order-lg-1`;
- блок вкладок обернуть в `div.d-flex.flex-column.order-1.order-lg-2`, а оба блока — в общий `div.d-flex.flex-column`;
- у `#nav-tab` добавить класс `ka-tabs`;
- вместо `<iframe>` и `<video>` вставить `<div class="ratio ratio-16x9 … ka-player" data-ka-src="URL" data-ka-poster="постер"></div>`;
- у фото заменить `col-lg-3` на `col-6 col-lg-3`, alt сделать `Кадр со съёмок фильма «…», фото N`;
- на телефоне добавить кнопку «Провести киноурок» над вкладками (`d-lg-none`).

## Шаг 5. Страницы кабинета

Все стили уже в `kinouroki-adaptive.css`, раздел 6. В шаблонах нужно поправить:
- **Практики** (`practies/index`, в копии `cabinet/practices.blade.php`): обернуть форму фильтра в `<details class="ka-filter-details" open><summary class="btn btn-outline-primary w-100 d-md-none">Фильтр и сортировка</summary>…</details>`; у сетки добавить `row-cols-sm-2 g-3`; удалить `<style>` из карточки; у чекбоксов добавить `id`; к `ul.pagination` добавить класс `ka-pagination flex-wrap`, а для компактной пагинации Laravel на телефоне можно использовать `->onEachSide(1)`; добавить пустое состояние.
- **Киноуроки** (`lessons/index`, `lessons/show`): у метки качества добавить класс `ka-pill-wrap`, у ссылки на файл — `ka-break`.
- **Статистика**: заменить `data-toggle` на `data-bs-toggle`, `data-target` на `data-bs-target`, `class="close"` на `class="btn-close"`, `data-dismiss` на `data-bs-dismiss`; во Vue-компоненте обернуть таблицы в `<div class="table-responsive">`.
- **Профиль** (`users/show`): класс `flex` заменить на `d-flex flex-wrap gap-2`, у кнопки новостей добавить `ka-btn-auto`, адрес обернуть в `ka-break`.

## Попутные исправления (см. AUDIT.md)

- В меню гостя пропущена скобка в Blade: `{ Route::is('documents.index', …) ? 'active' : '' }}`. Правильно: `{{ … }}`.
- `/premia` отдаёт 404, а ссылка на него есть в меню.
- Ссылка «Согласие родителей…» в разделе «Исследование» не открывается (см. закрытую папку команды).
- Опечатка «2924 года» у фильма «Думать тишину».

## Как проверить

Открыть каталог и страницу любого фильма на ширине 375, 768 и 1366 px. Горизонтальной прокрутки быть не должно, название фильма должно читаться целиком, а видео на телефоне — стоять выше описания.
