# Журнал изменений (реестр KA)

Здесь перечислено каждое улучшение копии по сравнению с боевым lk.kinouroki.org. У каждого изменения есть номер **KA-NNN**. Этот же номер стоит в коде рядом с правкой: в Blade в виде `{{-- KINOUROKI-ADAPTIVE [KA-NNN] --}}`, в CSS и JS в виде `[KA-NNN]`. Поэтому любое изменение находится поиском по номеру.

**Как пользоваться при обновлении сайта**
1. Выбрать строки со статусом «в копии».
2. Для каждой строки найти в коде копии её номер (`grep -rn "KA-014" laravel/`) и перенести правку в файл прода из колонки «Куда на проде».
3. Проверить на телефоне (375 px) и компьютере (1366 px) и поставить статус «на проде» с датой.

Столбец «Риск»: **Н** — только внешний вид; **С** — меняется разметка шаблона; **В** — меняется логика (контроллер, модель, запросы).

**Выводы для разработчика.** Регистр и ё/е уже учитываются на уровне базы. Кавычки и знаки препинания в запросе ломают поиск. Поиск идёт только по названию. Ответ приходит за 3–12 секунд: `LIKE '%…%'` перебирает около 108 тыс. строк. Рекомендации:
1. Нормализовать запрос, как в KA-032.
2. Искать также по фильму, качеству и учреждению.
3. Добавить полнотекстовый индекс (MySQL FULLTEXT с парсером ngram) или внешний поиск через Laravel Scout (Meilisearch).
4. Кешировать счётчик «найдено».
